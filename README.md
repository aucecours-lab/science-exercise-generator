# Science Exercise Generator

## Preview

![Aucecours Lab Preview](assets/lab-preview.png)

Open-source AI tools for science education.

## Vision

This project aims to help teachers and students generate high-quality science exercises for middle and high school levels.

The goal is to build accessible educational AI tools focused on:
- mathematics
- physics
- chemistry
- biology

## Features

- Exercise generation
- Step-by-step corrections
- Difficulty adaptation
- Brevet-style exercises
- Scientific vocabulary support
- Teacher-friendly formatting

Early development phase.
